VegPro Smart Farm — Field User Manual

Product: VegPro Smart Farm (Scouting)

Live URL: https://scouting.kongoniriverfarm.com/

Audience: Field scouts (workers)

Version: October 2026 handover

This manual explains step-by-step how to scout correctly on the phone every day.

1. Sign in on the phone

  1. Connect the phone to farm Wi‑Fi or mobile data that can reach the site.
  2. Open Chrome (or Safari) and go to https://scouting.kongoniriverfarm.com/
  3. Choose Field worker.
  4. Enter your email and password → Sign in.
  5. Allow location / GPS when the browser asks (required for correct greenhouse assignment).

Your farm will give you your own login. Do not share passwords.

2. Open Field work

  1. Tap Field work in the menu (or open it from Home).
  2. Check Current assignment (farm / greenhouse).

- Normally this comes from live GPS (nearest greenhouse).

- If GPS is weak indoors, use Override greenhouse, pick the correct house, then continue.

3. Start a scout round

  1. Find Scout route (round controls).
  2. Tap Start round.
  3. Keep the round open while you walk the house and save stops.
  4. When finished, Complete the round so the route is closed for reporting.

4. Record a scout stop (main procedure)

  1. Tap Scout stop.
  2. Confirm farm / greenhouse shown at the top.
  3. Fill the form carefully:

- Category (e.g. Cut Rose)

- Variety

- Column / bay / beds as required

- Issue type — pest or disease

- Issue name from the list

- Rating (severity 1–5)

- Optional scouting parameters

- Notes if needed

  1. Tap Save.
  2. Wait for the success message before moving to the next stop.

Correct usage rules

  • Save only what you observed.
  • Use the list values (variety, pest, disease) — do not invent free-text names when a list exists.
  • If the greenhouse is wrong, fix Override greenhouse before saving.
  • Keep GPS on; each save stores coordinates for the farm map and routes.

5. Infestation / hotspot and spray (when used)

  1. From Field work, open the infestation / hotspot or spray action shown in training.
  2. Select the greenhouse / issue context.
  3. Attach evidence/photo if the form offers it.
  4. Save and confirm success.

6. End of shift

  1. Complete any open scout round.
  2. Sign out if the phone is shared.
  3. Do not leave the phone signed in as another person’s account.

7. Good practice

  1. Always use https://scouting.kongoniriverfarm.com/ (padlock in the browser).
  2. One person = one login.
  3. Keep location permission on for accurate greenhouse assignment.
  4. If the site does not load on farm Wi‑Fi but works on mobile data, tell your supervisor or IT.
  5. Report problems with: time, phone/browser, your email (not password), screen name, and what you expected.

8. Quick checklist (30 seconds)

  1. Sign in as Field worker
  2. Field work → GPS / greenhouse correct
  3. Start round
  4. Scout stop → fill lists → Save
  5. Complete round → Sign out if shared device
