This manual explains step-by-step how to use manager reports and spray logging correctly every day.

1. Sign in

  1. Open https://scouting.kongoniriverfarm.com/
  2. Choose Manager (Farm manager).
  3. Enter your email and password → Sign in.
  4. You should see the Farm manager menu.

3. Daily reports — Dashboard

  1. Open Dashboard.
  2. Read the KPI cards at the top (scouting stops, hotspots, sprays, workers in field, severe issues — as labelled).
  3. Check Needs attention / alerts.
  4. Scan the live activity feed for today’s field events.
  5. Use shortcuts to open Scouting, Map, Workers, or History when you need detail.

Correct usage: Start every morning on Dashboard before assigning spray or follow-up work.

4. Scouting reports (main operational report)

  1. Open Scouting.
  2. Review in this order:

1. Spray / work program — what needs spray today, within 48h, or monitoring only

2. Heat grid — where pressure is highest inside a greenhouse

3. Routes / stops — what scouts walked and recorded

4. Records table — full list of stops (house, variety, issue, rating, time)

  1. Change the greenhouse filter to compare houses.
  2. Use row/cell drill-down when available to see issue detail.

How to use this for decisions

  • High rating + repeated pest/disease → prioritise spray or agronomy visit.
  • Empty records for a house that should have been scouted → follow up with the scout team.
  • Do not edit scout observations from this screen; ask the scout to re-record if a correction is needed.

5. Map usage

  1. Open Map.
  2. Identify open hotspots and spray-related pins.
  3. Select a pin/item when the UI allows.
  4. If actions such as Mark sprayed or Resolved appear, use them only when the physical work is done.

Correct usage: Map is for location awareness and status updates — always confirm in the greenhouse before marking complete.

6. Workers view

  1. Open Workers.
  2. Check who is active in the field and related greenhouse / problem context.
  3. Use this to coordinate which scout covers which house.

7. Log spray

  1. Open Log spray.
  2. Enter the spray / treatment details required on the form (greenhouse, product/context, notes as shown).
  3. Save and confirm success.
  4. Re-check Dashboard or Map if you expect the status to update.

8. History reports

  1. Open History.
  2. Review multi-period views and greenhouse health / improvement style charts.
  3. Use History for weekly reviews with agronomy — use Scouting for same-day operations.

9. Good practice

  1. Always use https://scouting.kongoniriverfarm.com/ (padlock in the browser).
  2. One person = one login.
  3. If the site does not load on farm Wi‑Fi but works on mobile data, tell IT.
  4. Report problems with: time, device/browser, your email (not password), screen name, and what you expected.

10. Quick checklist (30 seconds)

  1. Sign in as Manager
  2. Dashboard → alerts
  3. Scouting → spray program + heat grid + records
  4. Map → hotspots
  5. Log spray when treatments are done
  6. History for weekly review
